From inbox to overview

One place to follow
your transactions.

  1. 01

    Read transaction emails

    Authorize Gmail read-only access. FinVault retrieves emails from the Gmail labels configured for ingestion.

  2. 02

    Build a local record

    Supported email formats are parsed into transactions. Email records and extracted transaction data are stored in SQLite on the host running FinVault.

  3. 03

    Review the bigger picture

    Use the dashboard to view transaction history and summaries of income, spending, and cash flow. Check the original records when accuracy matters.
