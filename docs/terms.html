Using FinVault

Terms of use

FinVault is a personal software project for self-hosted financial recordkeeping. These terms describe the intended use and practical responsibilities of running it.

Personal recordkeeping

FinVault helps retrieve transaction emails, extract supported transaction details, and display financial summaries. It is intended for personal use on infrastructure you operate.

Its output is informational. It is not financial, investment, tax, or legal advice, and it should not be treated as an authoritative bank statement or accounting record.

Use accounts you are authorized to access

Connect only Gmail accounts and process only data you are authorized to access. Follow the applicable terms for Google APIs and any other services used with your installation. Read the privacy notice before granting Gmail access.

Your installation

You are responsible for configuring and maintaining your host, restricting access to the dashboard and API, handling credentials and tokens, and managing stored records and any backups you choose to create. Decide how long to keep data and how to remove it when it is no longer needed.

Publishing this informational website does not run the FinVault application. Your self-hosted installation needs its own setup, maintenance, and access controls.

Verify the results

Email formats can change, parsing can fail, and retrieved records may be incomplete or incorrect. Check transactions and summaries against original emails and statements before making decisions or relying on them for reporting.

Stopping use and following changes

You can stop using FinVault by stopping the application and scheduled ingestion, revoking Google access, and managing local data deletion and deletion of any backups you created. See the privacy notice for details.

Check the project repository and these pages when updating. Return to the project overview for a description of FinVault.
